# 📊 Dataset

## Overview

This folder contains the dataset used for the **Wine Quality Prediction** project.

The dataset contains physicochemical measurements of red wine samples along with their corresponding quality scores. It was used for data analysis, visualization, SQL analysis, and machine learning.

## Dataset Details

* **Records:** 1,143
* **Columns:** 13
* **Target Variable:** `quality`
* **Identifier:** `Id`
* **Missing Values:** None
* **Duplicate Records:** None

## Features

The dataset contains the following variables:

| Feature                | Description                  |
| ---------------------- | ---------------------------- |
| `fixed acidity`        | Fixed acidity level          |
| `volatile acidity`     | Volatile acidity level       |
| `citric acid`          | Citric acid level            |
| `residual sugar`       | Residual sugar content       |
| `chlorides`            | Chloride concentration       |
| `free sulfur dioxide`  | Free sulfur dioxide level    |
| `total sulfur dioxide` | Total sulfur dioxide level   |
| `density`              | Density of the wine          |
| `pH`                   | Acidity level measured by pH |
| `sulphates`            | Sulphate concentration       |
| `alcohol`              | Alcohol percentage           |
| `quality`              | Wine quality score           |
| `Id`                   | Unique wine identifier       |

## Data Preparation

The dataset was inspected and validated before analysis. The following checks were performed:

* Checked the dataset structure and data types.
* Checked for missing values.
* Checked for duplicate records.
* Verified the uniqueness of the `Id` column.
* Reviewed the distribution of wine quality scores.
* Prepared the dataset for SQL analysis, visualization, and machine learning.

## Usage

The dataset was used throughout the project for:

* Exploratory Data Analysis using Python
* SQL analysis using MySQL
* Power BI dashboard development
* Tableau dashboard development
* Machine Learning prediction using Random Forest

## Source

The dataset is the **Wine Quality dataset (WineQT)** used for this project.
