# 📊 Tableau Dashboard

## Overview

This folder contains the **Tableau dashboard** developed for the Wine Quality Prediction project.

Tableau was used to create an interactive visual analysis of the Wine Quality dataset and present key findings in a clear and accessible format.

## 🛠️ Tool

* Tableau Desktop

## 📈 Dashboard Overview

The Tableau dashboard provides an interactive view of wine quality and the physicochemical characteristics of the wines.

### Key Performance Indicators

The dashboard includes KPI cards highlighting:

* **Total Wine Records:** 1,143
* **Average Quality:** 5.66
* **Average Alcohol:** 10.44
* **Average pH:** 3.31

### Visual Analysis

The dashboard explores:

* Wine quality distribution
* Alcohol levels
* pH
* Acidity
* Sulphates
* Other physicochemical properties
* Patterns across different quality scores

Interactive Tableau visualizations allow users to explore the dataset and identify patterns in wine characteristics and quality.

## 🎨 Dashboard Design

The dashboard was designed to present the analysis in a clear and visually engaging format.

It includes:

* KPI cards
* Interactive charts
* Data visualizations
* Clear labels
* Consistent formatting
* Interactive filtering where applicable

## 🎯 Purpose

The purpose of the Tableau dashboard is to communicate the key findings from the Wine Quality dataset through interactive and visually engaging data visualizations.

The Tableau dashboard complements the **Python, SQL, and Power BI** components of the project.

## 📁 Files

The Tableau folder contains the Tableau workbook used to create the dashboard.

## 🔑 Key Insights

The dashboard highlights that:

* Most wines have quality scores of **5 and 6**.
* The average wine quality is approximately **5.66**.
* The average alcohol level is approximately **10.44**.
* The average pH is approximately **3.31**.
* Wine characteristics vary across different quality scores.
