# 📸 Tableau Dashboard Screenshots

## Overview

This folder contains screenshots of the **Wine Quality Tableau dashboard** developed as part of the project.

The screenshots provide a visual preview of the completed Tableau dashboard and its key analytical components.

## 📊 Dashboard Preview

The screenshots showcase:

* KPI cards displaying key wine quality metrics
* Wine quality analysis
* Alcohol analysis
* pH analysis
* Other physicochemical characteristics
* Data visualizations
* Overall dashboard layout and design

## 🎯 Purpose

The screenshots provide a quick visual reference of the Tableau dashboard for users who want to view the analysis without opening the Tableau workbook.

The complete Tableau dashboard is available in the **Tableau** folder.
