# 🗄️ SQL Analysis

## Overview

This folder contains the SQL analysis completed for the **Wine Quality Prediction** project.

MySQL was used to query, analyze, and summarize the Wine Quality dataset. The SQL analysis provided additional insights into wine quality and the physicochemical characteristics of the wines.

## 🛠️ Tools & Technologies

* MySQL
* SQL

## 🔍 SQL Analysis Workflow

### 1. Database & Table Setup

The Wine Quality dataset was imported into MySQL and structured into a database table for analysis.

### 2. Data Validation

SQL queries were used to examine the dataset and validate the imported data.

The analysis included:

* Checking the number of records
* Reviewing the available columns
* Checking for missing values
* Checking for duplicate records
* Examining unique wine quality scores
* Reviewing minimum, maximum, and average values

### 3. Data Analysis

SQL queries were used to analyze:

* Wine quality distribution
* Average wine quality
* Alcohol levels
* pH levels
* Acidity measurements
* Sulphates
* Other physicochemical properties
* Relationships between wine characteristics and quality

### 4. Aggregation & Filtering

SQL aggregation and filtering techniques were used to summarize the data and identify patterns across different wine quality scores.

Key SQL techniques included:

* `SELECT`
* `WHERE`
* `GROUP BY`
* `ORDER BY`
* Aggregate functions such as `COUNT()`, `AVG()`, `MIN()`, and `MAX()`
* Conditional filtering

## 📊 Key Findings

The SQL analysis supported the overall project findings, including:

* The dataset contains **1,143 wine records**.
* Wine quality scores range from **3 to 8**.
* Most wines have quality scores of **5 and 6**.
* The average wine quality is approximately **5.66**.
* The average alcohol level is approximately **10.44**.
* The average pH is approximately **3.31**.

## 🎯 Purpose

The SQL analysis demonstrates the use of relational database querying and analytical SQL techniques to extract meaningful information from a real-world dataset.

The results from the SQL analysis contributed to the overall findings presented through the project's **Power BI and Tableau dashboards**.
