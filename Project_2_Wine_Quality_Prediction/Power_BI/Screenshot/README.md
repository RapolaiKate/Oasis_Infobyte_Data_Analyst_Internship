# 📸 Power BI Dashboard Screenshots

## Overview

This folder contains screenshots of the **Wine Quality Power BI dashboard** developed as part of the project.

The screenshots provide a visual preview of the completed dashboard and its key analytical components.

## 📊 Dashboard Preview

The screenshots showcase:

* KPI cards displaying key wine quality metrics
* Wine quality distribution
* Alcohol analysis
* pH analysis
* Other physicochemical characteristics
* Interactive dashboard visualizations
* Overall dashboard layout and design

## 🎯 Purpose

The screenshots provide a quick visual reference of the Power BI dashboard for users who want to view the analysis without opening the `.pbix` file.

The complete interactive dashboard is available in the **Power BI** folder.
