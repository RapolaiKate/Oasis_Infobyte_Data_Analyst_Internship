# 📊 Power BI Dashboard

## Overview

This folder contains the **Power BI dashboard** developed for the Wine Quality Prediction project.

Power BI was used to transform the wine dataset into an interactive dashboard that provides a clear overview of wine quality and its key physicochemical characteristics.

## 🛠️ Tool

* Microsoft Power BI

## 📈 Dashboard Overview

The dashboard provides an interactive view of the Wine Quality dataset using KPI cards and visualizations.

### Key Performance Indicators

The dashboard includes:

* **Total Wine Records:** 1,143
* **Average Quality:** 5.66
* **Average Alcohol:** 10.44
* **Average pH:** 3.31

### Visual Analysis

The dashboard explores:

* Wine quality distribution
* Alcohol levels
* pH
* Acidity
* Sulphates
* Other wine characteristics
* Patterns across different quality scores

Interactive Power BI visuals allow users to explore the data and identify patterns in wine quality.

## 🎨 Dashboard Design

The dashboard was designed to present the analysis in a clear and easy-to-understand format.

It uses:

* KPI cards for key metrics
* Charts for distribution and comparison
* Interactive filtering
* Clear labels and visual hierarchy
* A consistent dashboard layout

## 🎯 Purpose

The purpose of the Power BI dashboard is to transform the analytical results into an interactive business intelligence report that makes wine quality patterns easier to understand.

The dashboard complements the **Python, SQL, and Tableau** analysis completed as part of the project.

## 📁 Files

The Power BI folder contains the `.pbix` dashboard file used to create the report.

## 🔑 Key Insights

The dashboard highlights that:

* Most wines have quality scores of **5 and 6**.
* The average wine quality is approximately **5.66**.
* The average alcohol level is approximately **10.44**.
* The average pH is approximately **3.31**.
* Wine characteristics vary across different quality scores.
