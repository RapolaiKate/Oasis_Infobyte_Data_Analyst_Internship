# 🤖 Machine Learning

## Overview

This folder contains the machine learning work completed for the **Wine Quality Prediction** project.

A **Random Forest Regression** model was developed to predict wine quality based on the physicochemical characteristics of the wine.

## 🛠️ Tools & Technologies

* Python
* Pandas
* NumPy
* Scikit-learn
* Random Forest Regression

## 🎯 Objective

The objective of the machine learning component was to determine whether the physicochemical properties of wine could be used to predict its quality score.

## 🔍 Machine Learning Workflow

### 1. Feature Selection

The wine's physicochemical characteristics were used as predictive features, while `quality` was selected as the target variable.

The `Id` column was not used as a predictive feature because it serves as an identifier rather than a meaningful wine characteristic.

### 2. Train-Test Split

The dataset was divided into training and testing sets:

* **Training set:** 914 records
* **Testing set:** 229 records

This allowed the model to be trained on one portion of the data and evaluated on unseen data.

### 3. Model Development

A **Random Forest Regression** model was trained using the training dataset.

Random Forest was selected because it can capture non-linear relationships between multiple wine characteristics and the target variable.

### 4. Prediction

The trained model was used to predict wine quality for the test dataset.

The predicted values were compared with the actual wine quality scores.

### 5. Results

The prediction results were exported to a CSV file containing the actual and predicted quality values.

These results can be used to evaluate how closely the model's predictions correspond to the actual wine quality scores.

## 📊 Prediction Output

The machine learning folder contains the prediction results generated by the Random Forest model.

The output includes:

* Actual wine quality
* Predicted wine quality

These results provide a basis for comparing model predictions against the actual values.

## 🎯 Purpose

The machine learning component demonstrates the application of predictive modeling to a real-world dataset.

It complements the **Python, SQL, Power BI, and Tableau** components of the project by extending the analysis from descriptive insights to predictive analysis.
