# 🐍 Python Analysis

## Overview

This folder contains the Python data analysis work completed for the **Wine Quality Prediction** project.

Python was used to inspect, clean, validate, and explore the Wine Quality dataset and to generate visualizations that helped identify patterns and relationships within the data.

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib

## 🔍 Analysis Workflow

### 1. Data Loading & Inspection

The dataset was loaded into Python and inspected to understand its structure and contents.

The analysis included:

* Reviewing the number of rows and columns
* Examining data types
* Checking dataset information
* Reviewing descriptive statistics
* Inspecting the distribution of variables

### 2. Data Cleaning & Validation

The dataset was checked to ensure it was suitable for analysis.

The following validation checks were performed:

* Checked for missing values
* Checked for duplicate records
* Verified unique wine IDs
* Reviewed data types
* Checked the overall consistency of the dataset

The dataset contained **1,143 records and 13 columns**, with no missing values or duplicate records.

### 3. Exploratory Data Analysis

Exploratory Data Analysis (EDA) was performed to understand the characteristics of the wine dataset.

The analysis examined:

* Wine quality distribution
* Alcohol levels
* pH
* Acidity
* Sulphates
* Other physicochemical properties
* Relationships between wine characteristics and quality

### 4. Data Visualization

Matplotlib was used to create visualizations that helped communicate patterns and distributions within the dataset.

The visual analysis supported the investigation of:

* Quality score distribution
* Variable distributions
* Relationships between wine characteristics
* Patterns across different quality levels

## 📊 Key Findings

The Python analysis showed that:

* The dataset contains **1,143 wine records**.
* Wine quality scores range from **3 to 8**.
* Most wines have quality scores of **5 and 6**.
* The average wine quality is approximately **5.66**.
* The average alcohol level is approximately **10.44**.
* The average pH is approximately **3.31**.

## 🎯 Purpose

The Python analysis provided the foundation for the rest of the project by ensuring that the dataset was properly understood, validated, and explored before being used for further analysis and visualization.

The machine learning work is documented separately in the **Machine Learning** folder.
