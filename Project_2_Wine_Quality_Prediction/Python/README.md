# 🐍 Python Analysis

## Overview

This folder contains the Python analysis and machine learning work completed for the **Wine Quality Prediction** project.

Python was used to inspect and prepare the dataset, perform exploratory data analysis, visualize patterns, and develop a machine learning model for predicting wine quality.

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-learn

## Analysis Workflow

The Python analysis included:

### 1. Data Inspection

* Loaded the Wine Quality dataset.
* Examined the dataset structure, dimensions, and data types.
* Checked for missing values and duplicate records.
* Reviewed descriptive statistics.

### 2. Data Cleaning & Validation

* Verified data quality and consistency.
* Confirmed that there were no missing values or duplicate records.
* Checked the uniqueness of wine IDs.
* Prepared the dataset for analysis and modeling.

### 3. Exploratory Data Analysis

The analysis explored:

* Wine quality distribution
* Alcohol levels
* pH
* Acidity
* Sulphates
* Other physicochemical properties
* Relationships between wine characteristics and quality

### 4. Machine Learning

A **Random Forest Regression** model was developed to predict wine quality.

The dataset was divided into:

* **Training set:** 914 records
* **Testing set:** 229 records

The `quality` variable was used as the target, while the physicochemical characteristics were used as predictive features.

The model predictions were compared with the actual quality values to evaluate the prediction results.

## Output

The Python analysis produced:

* Exploratory data analysis results
* Data visualizations
* Machine learning predictions
* Actual vs. predicted wine quality results

The prediction results were exported for further analysis and visualization.
