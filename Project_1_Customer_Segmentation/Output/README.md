# RFM Customer Segmentation Output

## 📌 Overview

This folder contains the final output generated from the **Customer Segmentation Analysis** project completed as part of the **Oasis Infobyte Data Analytics Internship**.

The output contains customer-level RFM metrics, RFM scores, and customer segments generated after analyzing the cleaned transaction data.

## 📄 Output File

**File:** `RFM_Customer_Segmentation.csv`

## 📊 Output Description

The final output contains the results of the RFM analysis, including information used to understand each customer's purchasing behavior.

The main RFM metrics are:

- **Recency** – Number of days since the customer's most recent purchase.
- **Frequency** – Number of purchases made by the customer.
- **Monetary** – Total amount spent by the customer.
- **RFM Scores** – Scores assigned to customers based on their Recency, Frequency, and Monetary values.
- **Customer Segment** – Final customer classification based on the RFM analysis.

## 👥 Customer Segments

Customers were classified into five segments:

- **Champions**
- **Loyal Customers**
- **Potential Loyalists**
- **At Risk**
- **Lost Customers**

## 📈 Final Segmentation Results

The analysis identified **4,372 customers** across the five segments:

| Customer Segment | Customers | Percentage |
|---|---:|---:|
| Potential Loyalists | 1,114 | 25.48% |
| Loyal Customers | 990 | 22.64% |
| Champions | 949 | 21.71% |
| At Risk | 782 | 17.89% |
| Lost Customers | 537 | 12.28% |
| **Total** | **4,372** | **100%** |

## 🎯 Purpose

The output dataset was created to support:

- Customer segmentation.
- Customer retention analysis.
- Identification of high-value customers.
- Identification of customers at risk of becoming inactive.
- Customer loyalty analysis.
- Targeted marketing strategies.
- Business decision-making.

## 💡 Business Value

The RFM output allows businesses to understand customer value and develop different strategies for different customer groups.

For example:

- **Champions** can be rewarded and retained.
- **Loyal Customers** can be encouraged to continue purchasing.
- **Potential Loyalists** can be converted into more loyal customers.
- **At Risk** customers can be targeted with re-engagement campaigns.
- **Lost Customers** can be targeted with win-back strategies.
