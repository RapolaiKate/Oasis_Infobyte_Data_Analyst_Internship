# Charts

## 📊 Overview

This folder contains the visualizations created during the **Customer Segmentation Analysis** project for the **Oasis Infobyte Data Analytics Internship**.

The charts were created using **Python, Pandas, and Matplotlib** and were used to communicate the results of the RFM analysis in a clear and visual way.

## 📈 Charts Included

### 1. Customer Segmentation Based on RFM Analysis

Shows the number of customers assigned to each RFM customer segment.

### 2. Average Customer Spending by Segment

Compares the average amount spent by customers across the different customer segments.

### 3. Average Recency by Customer Segment

Shows the average number of days since the most recent purchase for each customer segment.

### 4. Customer Segment Distribution

Shows the proportion and distribution of customers across the different RFM segments.

### 5. Average Frequency by Customer Segment

Compares the average purchase frequency across the different customer segments.

## 🎯 Purpose

These visualizations help communicate the RFM analysis results and make it easier to identify:

- High-value customers.
- Loyal customers.
- Potential loyal customers.
- Customers who are at risk.
- Lost customers.
- Differences in customer purchasing behavior.

The complete analysis and code used to create these visualizations are available in the **Oasis_Infobyte_Customer_Segmentation.ipynb** notebook.
