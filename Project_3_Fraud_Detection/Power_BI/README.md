# 📊 Power BI Dashboard

## Overview

Power BI was used to create an interactive **Credit Card Fraud Detection Dashboard** for analysing transaction activity and identifying patterns associated with fraudulent transactions.

The dashboard presents key fraud metrics and visual insights in an easy-to-understand format.

## 🛠️ Tools Used

* Microsoft Power BI
* Power Query
* Data modelling
* DAX
* Interactive visualizations

## 📊 Dashboard KPIs

The dashboard includes the following key performance indicators:

| KPI                        |      Value |
| -------------------------- | ---------: |
| Total Transactions         |    **10K** |
| Fraudulent Transactions    |    **151** |
| Fraud Rate                 |  **1.51%** |
| Average Transaction Amount | **175.92** |

These KPIs provide a quick overview of the transaction dataset and the scale of fraudulent activity.

## 📈 Dashboard Visualizations

The dashboard includes visualizations analysing:

* Fraudulent vs. legitimate transactions
* Fraud by merchant category
* Foreign transactions
* Location mismatches
* Transaction hours
* Device trust scores

These visuals allow users to explore different characteristics of transactions and identify potential fraud-related patterns.

## 🎨 Dashboard Design

The dashboard was designed with a professional dark-themed layout:

* Dark navy background
* White dashboard header
* White KPI cards
* Gold KPI values
* Clear charts and labels

The design was intended to provide good visual contrast while keeping the dashboard professional and easy to interpret.

## 🔍 Key Insights

The dashboard highlights that:

* The dataset contains **10,000 transactions**.
* **151 transactions** are fraudulent.
* Fraud accounts for approximately **1.51%** of all transactions.
* The majority of transactions are legitimate.
* Fraud patterns can be explored across merchant categories, transaction hours, foreign transactions, location mismatches, and device trust scores.

## 🎯 Dashboard Purpose

The Power BI dashboard was created to:

* Monitor transaction activity
* Analyse fraudulent transactions
* Identify potential fraud patterns
* Present important fraud KPIs
* Support data-driven decision-making
* Transform transaction data into interactive business insights
