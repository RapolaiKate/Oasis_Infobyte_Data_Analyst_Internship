# 📊 Tableau Dashboard

## Overview

Tableau was used to create an interactive **Credit Card Fraud Detection Dashboard** to analyse transaction activity and identify patterns associated with fraudulent transactions.

The dashboard transforms transaction data into interactive visualizations that make fraud-related patterns easier to explore and understand.

## 🛠️ Tools Used

* Tableau Desktop
* Data visualization
* Calculated fields
* Filters
* Interactive dashboard components

## 📊 Dashboard KPIs

The Tableau dashboard includes the following key performance indicators:

| KPI                        |     Value |
| -------------------------- | --------: |
| Total Transactions         |   **10K** |
| Fraudulent Transactions    |   **151** |
| Fraud Rate                 | **1.51%** |
| Average Transaction Amount | **175.9** |

These KPIs provide a quick overview of transaction activity and fraudulent behaviour.

## 📈 Dashboard Visualizations

The dashboard analyses fraud across several transaction characteristics, including:

* Fraudulent vs. legitimate transactions
* Merchant categories
* Foreign transactions
* Location mismatches
* Transaction hours
* Device trust scores

These visualizations allow users to explore transaction patterns and compare fraudulent activity across different categories.

## 🎨 Dashboard Design

The Tableau dashboard was designed to present fraud-related information clearly and professionally.

The dashboard focuses on:

* Clear KPI cards
* Easy-to-read charts
* Consistent formatting
* Interactive visual analysis
* Simple and informative presentation

## 🔍 Key Insights

The Tableau analysis highlights that:

* The dataset contains **10,000 transactions**.
* **151 transactions** are fraudulent.
* The overall fraud rate is **1.51%**.
* Most transactions are legitimate.
* Fraudulent activity can be explored across merchant categories, transaction hours, foreign transactions, location mismatches, and device trust scores.

## 🎯 Dashboard Purpose

The Tableau dashboard was created to:

* Analyse transaction behaviour
* Identify fraud-related patterns
* Monitor key fraud metrics
* Explore transaction characteristics interactively
* Communicate analytical findings visually
* Support data-driven decision-making

## 📁 Project Files

The Tableau folder contains the Tableau workbook and supporting dashboard screenshots used to document the project.

The dashboard forms part of the wider fraud detection project alongside **Python, SQL, Power BI, and Machine Learning**.

## ✅ Conclusion

The Tableau dashboard provides an interactive visual analysis of credit card transactions and fraudulent activity. By combining KPI metrics with multiple transaction-level visualizations, Tableau helps communicate important fraud patterns and insights clearly.
