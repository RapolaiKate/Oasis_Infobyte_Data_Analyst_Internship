# 📸 Tableau Dashboard Screenshots

## Overview

This folder contains screenshots of the **Credit Card Fraud Detection Tableau Dashboard**.

The screenshots provide a visual reference of the completed dashboard and its key fraud analysis components.

## 📊 Dashboard Contents

The dashboard screenshots showcase:

* Total Transactions KPI
* Fraudulent Transactions KPI
* Fraud Rate KPI
* Average Transaction Amount KPI
* Fraud vs. Legitimate Transactions
* Fraud by Merchant Category
* Foreign Transaction Analysis
* Location Mismatch Analysis
* Transaction Hour Analysis
* Device Trust Score Analysis

## 🎯 Purpose

The screenshots document the final Tableau dashboard and demonstrate how transaction data was transformed into interactive visual insights for fraud analysis.

They can be viewed alongside the Tableau workbook to understand the final dashboard layout and presentation.
